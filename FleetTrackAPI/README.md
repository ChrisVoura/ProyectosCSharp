# FleetTrack API

API REST para gestión de transporte y entregas empresariales.

## Tecnologías
- ASP.NET Core / C# / .NET 10
- Entity Framework Core + SQLite
- JWT + BCrypt
## Autenticación
Todos los endpoints requieren JWT excepto `/api/auth/registro` y `/api/auth/login`.
